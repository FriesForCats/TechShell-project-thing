# TechShell-project-thing
Made by Kyrylo 'Kat' Prykhodchenko

A basic shell made to mimic a bash shell done for my systems programming class 

You can use this by inputting "git clone (url)" into a terminal (assuming you have git installed)\n
after that input "gcc TechShell.c -o TechShell" to compile it\n
and then finally anytime you want to run the program you would do "./TechShell"\n

That should be it outside of having c on your computer and such.
